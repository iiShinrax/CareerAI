# CareerAI Knowledge Base Plan

## 1. Project

CareerAI — AI Career & Interview Assistant

## 2. Target Users

Students and junior professionals looking for:
- Internships
- Entry-level jobs
- Career guidance
- Interview preparation

## 3. Target Career Roles

- AI Engineer
- Machine Learning Engineer
- Data Scientist
- Data Analyst
- NLP Engineer
- Computer Vision Engineer
- Data Engineer
- Software Engineer
- Backend Developer
- Frontend Developer
- Full Stack Developer
- Cloud Engineer
- DevOps Engineer
- Cybersecurity Analyst
- Research Scientist

## 4. Knowledge Categories

### Occupations
Information about different career roles and their responsibilities.

### Skills
Technical and professional skills required for each role.

### Technology Skills
Programming languages, frameworks, tools, platforms, and technologies.

### Responsibilities
Typical tasks and responsibilities for each occupation.

### Career Paths
Possible progression between roles and career levels.

### Education Requirements
Common educational requirements and relevant fields of study.

### Interview Preparation
Technical, behavioral, HR, and role-specific interview information.

### CV / ATS Guidance
CV structure, project descriptions, skills sections, and ATS considerations.

### Learning Resources
Recommended topics and learning paths for closing skill gaps.

### Job Requirements
Real-world job requirements used for job matching.

## 5. RAG Use Cases

The RAG system should support:

1. Career questions
2. Career analysis
3. Job matching
4. Skill-gap analysis
5. Career roadmap generation
6. CV improvement
7. Interview preparation

## 6. Primary Data Sources

- O*NET
- Public career resources
- Public job descriptions
- Public educational/career resources

## 7. Metadata

Each document/chunk should contain:

- document_id
- source
- source_url
- category
- occupation
- topic
- skill
- date_added

## 8. RAG Pipeline

Documents
→ Cleaning
→ Chunking
→ Embeddings
→ Vector Database
→ Retrieval
→ Relevant Context
→ LLM
→ Grounded Response

## 9. Evaluation

The RAG system will initially be evaluated using 30–50 questions covering:

- Occupations
- Skills
- Technologies
- Responsibilities
- Career paths
- Job requirements
- Skill gaps
- Career recommendations
